Sobre este proyecto

AutoCatálogo es una aplicación web hecha como proyecto de medio ciclo. Muestra autos reales de varias marcas y permite enviar una consulta mediante un formulario.

Con qué está hecha

  • HTML5 para la estructura de las páginas.
  • CSS3 con Flexbox, Grid y media queries para que se vea bien en celular.
  • JavaScript puro para el buscador, los filtros, los favoritos y la validación del formulario.

Preguntas frecuentes

¿Los autos están a la venta?

No. Es un proyecto académico, por eso el catálogo no incluye precios y la información es solo referencial.

¿Qué pasa cuando envío el formulario?

El formulario solo valida los datos y muestra un mensaje de confirmación. No se envía a ningún servidor.

¿Se guardan mis favoritos?

Sí, se guardan en tu navegador para que los veas también en la página de contacto.
